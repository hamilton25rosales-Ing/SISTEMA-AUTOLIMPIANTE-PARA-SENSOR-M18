Diseño CAD de soporte para sensor tubular M18 con sistema de autolimpieza por aire

Descripción
Este proyecto consiste en el diseño de un soporte ajustable para sensor tubular M18 junto con un sistema modular de autolimpieza mediante aire comprimido.
La solución fue desarrollada como Proof of Concept para la asignatura Industria 4.0: Transformación Industrial Digital.

Objetivo
Diseñar un sistema que reduzca la acumulación de polvo y partículas sobre sensores industriales, mejorando la confiabilidad de detección y reduciendo las intervenciones de mantenimiento.

Tecnologías utilizadas
SketchUp Web
Ultimaker Cura
Impresión 3D (Manufactura Aditiva)
GitHub

Componentes diseñados
Base ajustable tipo L
Permite la fijación y calibración de sensores tubulares M18 mediante ranuras de ajuste.
Anillo de autolimpieza
Incorpora una entrada neumática y una cámara interna que distribuye aire comprimido alrededor de la cara activa del sensor.
